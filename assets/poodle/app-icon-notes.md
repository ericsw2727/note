# 강아지 얼굴 EXE 아이콘

app-icon.ico: 16, 24, 32, 48, 64, 128, 256px를 포함하는 Windows 아이콘.
app-icon.png: 투명 배경 원본.

내장 image_gen으로 기존 푸들의 얼굴만 정면으로 생성. 프롬프트: same cream apricot curly poodle face, both floppy ears, no body or accessories, readable dark eyes and nose, transparent background, single Windows application icon. Pillow로 ICO 형식 변환.

파일만 준비했으며 코드, 빌드 설정, 기존 EXE는 변경하지 않음.
