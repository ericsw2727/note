# 진주빛 젤 캐릭터 12종 에셋

2026-11-26. 선택된 반투명 진주빛·젤 3D 시안의 전체 캐릭터를 기본 포즈로 준비했다.

## 구성
- jelly-01-04.png 및 jelly-05-08.png: 1254×1254 투명 PNG, 각 2×2 셀.
- jelly-09-12.png: 1261×1247 투명 PNG, 2×2 셀. 원본 해상도가 달라 셀 크기는 JSON에 따로 기록했다.
- atlas.json: 총 12개 캐릭터별 ID, 이름, 이미지, [x,y,width,height] 영역.
- preview.html: 선택·밝은/어두운 배경·작은 크기 배치 예시. 각 캐릭터별 PNG 저장 버튼 제공.
- generation.json: 내장 image_gen의 전체 프롬프트 및 캐릭터 구성.

개별 파일로 사전 분할한 묶음이 아니라 시트 에셋이다. 앱은 JSON 영역을 읽어 사용한다. 개별 PNG가 필요하면 HTML의 각 저장 버튼을 누른다. HTML과 PNG를 같은 폴더에 둔다.

## 사용과 확인
원본 시안을 참조한 재생성이므로 원본 픽셀 그대로 잘라낸 것은 아니다. 외곽은 투명하지만 몸의 진주빛 광택과 입체감은 내부 색과 불투명도로 유지했다. 아주 작은 크기나 밝은 배경에서는 대비가 약할 수 있어 96px부터 확인하는 편이 좋다.

3개 PNG의 RGBA 형식·해상도·바깥 및 중앙 빈 영역 alpha=0을 확인하고 총 12개 셀 좌표를 작성했다. 브라우저에서의 표시·다운로드 동작 검증은 아직 하지 않았다. 기본 정적 포즈만 포함하며 걷기, 상태별 표정, 실제 앱 연결은 별도다. 기존 강아지와 앱·빌드 설정은 변경하지 않았다.
