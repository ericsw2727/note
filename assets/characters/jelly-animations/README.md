# 젤 캐릭터 기본 움직임 12종

2026-11-26. 전체 12종에 캐릭터당 4프레임 루프 시트를 추가했다. 총 48프레임. 내장 image_gen으로 기존 젤 시트의 해당 캐릭터를 참조했다. 전체 프롬프트는 generation.json에 있다.

## 전달 구성
- 캐릭터 ID별 PNG 12장: 각 1254×1254 RGBA, 2×2 셀, 셀 627×627. 좌상→우상→좌하→우하 순서.
- animations.json: 캐릭터, 움직임, 프레임 영역, 가시 영역, 재생 속도 및 반복 정보.
- data.js: 로컬 미리보기가 서버 없이 읽는 동일한 캐릭터 데이터.
- preview.html / player.js: 12종 동시 재생, 선택, 재생·정지, 프레임 넘기기, 속도, 배경, 좌우 이동.

## 앱에 적용할 때
기본 4fps로 0,1,2,3을 반복하고 실제 크기는 80~96px부터 확인한다. 시트의 각 셀을 읽고 캐릭터당 maxVisibleSize에 맞춘 고정 배율을 사용한다. visibleBounds로 프레임마다 가로 중심과 아래 위치를 정렬한다. 미리보기는 작은 상하 움직임(bob)과 좌우 이동을 별도로 합성한다. 원본 PNG는 가공하지 않았다. 빛나는 테두리 전체에 alpha가 있을 수 있어 가시 영역 분석은 alpha>=40 기준이다.

프레임은 직접 생성한 서로 다른 포즈이며 정적 이미지를 단순 이동시킨 것만은 아니다. 그러나 정밀하게 리깅한 애니메이션은 아니므로 광택·얼굴 비율·몸 크기 및 발 디딤에 약간 차이가 남는다. 곰과 여우는 원래 앉은 체형을 최대한 유지해 발을 번갈아 내미는 작은 동작이다. 자연스러운 실제 동물 보행을 보장하는 자료는 아니다.

외곽 alpha는 일부 시트 모서리에서 0, 일부는 1(255 중)이다. PNG를 불투명 배경으로 바꾸지 말고 RGBA로 불러온다. 원래 정적 시안의 픽셀 복제본이 아닌 참조 재생성이며 색과 형태에 소폭 차이가 있다.

## 범위와 기록
- 기본 움직임 1개 루프씩 총 12개를 제작했다. 대기·수면·알림·친구 접속 등 상태별 추가 동작은 이번 묶음에 없다.
- 기존 강아지와 앱·EXE·빌드 설정은 변경하지 않았다. 이 묶음을 앱에 연결하는 구현은 별도다.
- PNG 형식·크기, 48개 셀의 경계와 정렬 좌표를 검증했고 player.js 문법을 검사했다.

- Node의 모의 DOM/Canvas 환경에서 12개 이미지 경로, 카드 생성, 프레임 진행, 일시정지, 다음 프레임, 선택 전환, 이동 토글을 검사해 통과했다. 실제 브라우저 래스터 외형을 검사한 것은 아니다. Edge 헤드리스 실행은 실패해 실제 화면 및 다운로드 검토는 미완료다.
