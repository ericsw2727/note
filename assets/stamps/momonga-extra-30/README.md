# 모몽가 추가 스탬프 30종

2026-11-26. 기존 6종을 참조해 치이카와 모몽가 도장 스타일로 새 표정과 동작 30종 추가. 기존 에셋은 유지한다.

## 전달 구성
- set-01.png ~ set-05.png: 투명 PNG 시트 5장. 각 1536×1024, 3열×2행, 셀 512×512. 총 30종.
- atlas.json: 각 스탬프의 이름, ID, 이미지 파일, [x,y,width,height] 영역. 개별 PNG가 아니라 시트 좌표로 읽는 방식.
- preview.html: 30종을 선택해서 찍어볼 수 있는 로컬 미리보기. 별도 서버 없이 HTML과 이미지를 같은 폴더에 두고 연다.
- generation.json: 내장 image_gen에 전달한 전체 프롬프트, 포즈와 참조 파일 기록.

## 사용과 확인
앱에서 atlas의 rect 영역만 읽어 비율을 유지해 보통 96px부터 사용한다. 외곽은 투명하고 흰 캐릭터 몸과 일부 테두리 안쪽은 흰색이다. 잉크 질감과 테두리 형태는 세트마다 조금 다르다. 생성 에셋이며 공식 배포 원본은 아니다.

5개 시트의 RGBA 형식, 해상도, 모서리 alpha=0 및 총 30개 좌표를 확인했다. 프레임은 각 셀 안에서 읽도록 정의했다. 실제 앱 연결 및 브라우저에서 클릭 미리보기 동작 검증은 아직 하지 않았다. 프로그램·EXE·빌드·기존 파일은 변경하지 않았다.
