# 치이카와 모몽가 스탬프

2026-11-26. 동물 모몽가가 아니라 치이카와에 나오는 모몽가라는 사용자 정정을 반영.

stamps.png: 1536×1024 RGBA, 3열×2행, 한 칸 512×512. 좌상부터 인사, 하트, 칭찬, 잠자기, 놀람, 뒤돌아보기. atlas.json에 영역 정보. 외곽은 투명하고 캐릭터 몸은 흰색. preview.html에서 선택 후 클릭으로 찍기를 시험할 수 있음. 실제 앱과 빌드 설정은 변경하지 않음.

내장 image_gen 사용. 프롬프트: six rubber-stamp emoji of Momonga specifically from Chiikawa, white round body, light sky-blue curled tail, characteristic mischievous eyes, dark blue worn ink outlines, light blue spot ink and pink cheeks, 3x2 equal cells, wave/heart/praise/sleep/surprise/look-back, no words, transparent outside stamp, no 3D. 생성 이미지이므로 공식 원본 에셋이 아니다.

PNG 형식과 바깥 alpha를 확인함. 개별 PNG가 아닌 시트 형식이며 실제 낙서장 앱에 연결하는 구현은 별도 작업이다.
